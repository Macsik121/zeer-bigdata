Разработка распределённой системы обработки и анализа логов маркетплейса

Apache Hadoop экосистема • Lambda-архитектура • Machine Learning конвейер • 4-узловой кластер

📋

Суть проекта

Комплексное решение для сбора, хранения, обработки и анализа логов онлайн-маркетплейса Zeer Marketplace с использованием технологий Apache Hadoop экосистемы на физическом кластере из 4 узлов (1 Master + 3 Worker). Обработка трёх типов логов, Lambda-архитектура, 28 бизнес-метрик, ML-ко нвейер.
