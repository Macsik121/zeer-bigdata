# Проект по Большим Данным для маректплейса Zeer

Zeer-bigdata - набор документов по вопросам, которые выяснялись с Claude Code для разработки диплома по Обработке Больших Данных Логов системы Zeer marketplace. 

## Вот основные файлы, которые были созданы Claude Code:

### .claude/agents/
1. big-data-engineer.md - Промпт для инженера Больших данных, который разбирается и в технологической части Apache Hadoop и в инфраструктурной.

### analytics/

2. LOG_ANALYTICS_DESIGN.md - избыточная проработка возможных метрик, анализа логов и других идей для Анализа Больших Данных.

### docs/

3. CLICKFLOW_ANALYTICS_IMPLEMENTATION_PLAN.md - план реализации клода именно клик-флоу в маркетплейсе Zeer с дальнейшей возможностью масштабировать до Event Tracking.

4. DIPLOMA_DOCUMENTATION_STRUCTURE.md - избыточно подробная структура документации дипломной работы. Сначала нужно самому написать, а потом посмотреть, что можно добавить из того файла.

5. servers-infrastructure-software-implementation-plan.md - План реализации програмной части с ОС, сетевыми вещами и Hadoop через ADCM и ADH. План для дальнейших действий после самой сборки физических ПК. Также там приведён примерный код сервера на Node.js - является опорным для дальнейшей разработки.

6. code_according_to_servers_infrastructure_soft.txt - Сгенерированный код после утверждения плана реализации servers-infrastructure-software-implementation-plan.md . Туда не входит код сервера, записанный в плане. Реализация кода сервера будет продумана потом.

7. network-architecture.txt - анализ сетевых взаимодействий исходя из servers-infrastructure-software-implementation-plan.md . Анализ Phase 1, пункты 1.1 - 1.3.

8. PHYSICAL_SAFETY_AND_COOLING.md - подробное продумывание физической безопасности и охлаждения системы из 3-х ПК.
